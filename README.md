# Audiovisual Sequencer

シンプルで楽しい16ステップオーディオビジュアルシーケンサーアプリです。

## 特徴

- **Sine波ベースのサウンド合成**: FM変調を使用した可愛い音色
- **16ステップシーケンサー**: Kick、Snare、Hi-hat、Tomの4トラック
- **リアルタイムビジュアルエフェクト**: 音に同期した美しいグラフィック
- **直感的なUI**: 保育園から小学生でも楽しめるシンプルなデザイン
- **キーボードコントロール**: 素早い操作が可能

## 使い方

### 起動方法

1. `index.html` をブラウザで開く
2. PLAYボタンをクリックしてシーケンサーを開始

### 基本操作

- **ステップをクリック**: 音を配置/削除
- **パラメーター入力**: ステップをアクティブにすると、下の数値入力欄が有効になります（0.0-10.0）
- **フェーダー**: 各楽器の音色とビジュアルを変更

### キーボードショートカット

- **F**: Tomのビジュアルを三角錐⇄花モードに切り替え
- **R**: すべてのパラメーターをリセット（シーケンスパターンは保持）
- **Space**: Play/Stop

## 各楽器の特徴

### KICK (キック)
- **サウンド**: FM変調によるパンチのあるバスドラム
- **ビジュアル**: 2パターンが交互に表示
  - パターン1: 全画面フラッシュ
  - パターン2: 移動する白い四角
- **フェーダー1**: 歪み（distortion）とグリッチエフェクト

### SNARE (スネア)
- **サウンド**: トーン成分とノイズのミックス
- **ビジュアル**: シーケンサー周辺からの波紋エフェクト
- **フェーダー2**: フィードバック強度とサスティン（最大0.6秒）、ギザギザエフェクト

### HIHAT (ハイハット)
- **サウンド**: フィルターされたノイズ
- **ビジュアル**: 上から下へ落ちる細いライン
- **フェーダー3**: サスティンと線の太さ（最大40px）

### TOM (タム)
- **サウンド**: ピッチが変化するシンセティックドラム
- **ビジュアル**: 三角錐または花（Fキーで切り替え）
- **フェーダー4**: ピッチ変化（±7半音）とブラーエフェクト

## 技術仕様

- **BPM**: 123
- **ステップ数**: 16（16分音符）
- **オーディオエンジン**: Web Audio API
- **ビジュアルエンジン**: HTML5 Canvas
- **ブラウザ互換性**: モダンブラウザ（Chrome、Firefox、Safari、Edge）

## Tips

1. **リズムパターン**: まずキックとスネアで基本的なビートを作成
2. **ハイハット**: 連続してステップを配置すると、ビジュアルがsine波で滑らかに移動
3. **パラメーター調整**: 各ステップのパラメーターで微妙な音色変化を楽しめます
4. **フェーダー**: ライブ感を出すために、再生中にフェーダーを動かしてみましょう
